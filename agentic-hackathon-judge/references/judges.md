## 想定質問の例（作品に合わせて具体化して使う）

**佐藤さん観点**
- 初めて触る人が、最初の1分で価値を感じられますか？
- 想定利用者には、どうやって届けて、どう改善につなげますか？

**渡部さん観点**
- 技術的に独自な部分はどこですか？既存サービスとの分担は？
- このデモの後も継続開発・運用できる構成になっていますか？利用者が増えたら何が詰まりますか？
- AIで書いたコードや生成物の品質はどう確かめましたか？

**岡安さん観点**
- なぜ Google Cloud のこの構成なのですか？費用と運用負荷は？
- エージェントの成功・失敗はどの指標で測っていますか？
- どこまで自律実行させ、どこから人が確認しますか？

**栗原さん観点**
- 品質は何件、どんな条件で確認しましたか？
- 失敗するのはどんな条件ですか？そのとき利用者はどうなりますか？
- 既存手法や固定ルールと比べて何が良くなりましたか？

## 発表への落とし込み

4人に別々の説明を用意するより、1つのプロダクトを次の4面から説明できる状態にする。

| 面 | 準備するもの |
| --- | --- |
| 伝わる価値 | 困りごと → 現状の代替手段 → 改善後の体験を1つの具体例で |
| 実装 | 構成図、採用理由、独自実装と既存サービスの分担、実装済みと予定の区別 |
| データ活用 | データの流れ、Google Cloud を使う理由、費用・応答時間 |
| 品質 | 比較対象、測った指標、件数、失敗例。数値がなければ「未検証」と明記 |
