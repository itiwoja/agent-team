## 必須技術スタック（実行基盤とAI技術、それぞれ1つ以上）

**実行基盤**：App Engine／Compute Engine／GKE／Cloud Run／Cloud Run functions（旧 Cloud Functions）／Cloud TPU・GPU

**AI技術**：Gemini Enterprise Agent Platform（旧 Vertex AI。Model Garden・Vector Search 等を含む）／Gemini API／Gemma／Nano Banana／Agent Development Kit（ADK）／Speech-to-Text・Text-to-Speech API／Vision AI／Natural Language AI／Translation AI

**FAQ補足**
- Flutter・Firebase は任意（使う場合は提出フォームに記載）。
- AI Studio 経由の Gemini API も可。ただし実行基盤の条件は別途必要。
- Cloud Functions for Firebase・Firebase App Hosting は実行基盤の条件を満たす。Firebase Extension だけでは満たさない。
- Firebase 経由の Gemini API も AI技術の条件を満たす。

## 必須提出物

| 提出物 | 審査で見られること |
| --- | --- |
| GitHubリポジトリ | 公開・非公開どちらも可。主要機能の実装、今回の開発範囲・構成が分かること |
| デプロイURL | Google Cloud 上で動作。認証が必要なら審査用アカウント・サンプルデータ・確認手順。**ソーシャルログインやメール受信を必須にしない** |
| 説明 | 対象ユーザー、困りごと、解決方法、特徴 |
| 構成図 | システムアーキテクチャの画像 |

Zenn記事は任意（Ideaカテゴリ）。ネイティブアプリは可能ならWeb版を用意し、難しければ確認方法欄に事情を書く。

## 提出後の注意

- 締切後、説明・構成図・動画などの作品ページは一般公開（リポジトリとデプロイURLは非表示）。
