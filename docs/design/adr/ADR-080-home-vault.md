# ADR-080：家の保管庫（写真・書類）は本体の道具で扱い、消すのはゴミ箱へ
- 状態：承認（v1.7） ／ 日付：2026-10-26 ／ 決定者：ユーザー（写真・ファイルの管理、画像はクラウド既定）・Claude判断（形）
- 影響する ID：REQ-113・116, US-079・082, UC-068・071, FR-110・111・114, NFR-095, TBL-060・063, API-153・156, SCR-030, R-108・110, D-373・374・376

## 状況
写真やファイルの整理は、家の中にファイルがあるからこそ頼める仕事になる。今の設計では、エージェントのファイルは VM のホームだけで、家の写真や書類には届かない。VM の中は判定しない（ADR-061）ので、家のファイルを VM に直接つなぐと、消す・上書きするを止められない。

## 決定
- USB の SSD（または家の NAS を SMB で）を `makase-vault` としてつなぐ。フォルダは `写真`・`書類`・`レシート`・`書き出し`・`ゴミ箱`（D-373）
- 本体の道具 `vault_list`・`vault_read`・`vault_write`・`vault_move`・`vault_trash` で扱い、Kernel が判定する。消す＝ゴミ箱へ（30 日で消える。1 回の頼みで 20 件以上をまとめて移すときは人）。上書き＝前の版を残す（30 日）。ゴミ箱を空にする・30 日より前に消すのは必ず人
- VM には保管庫をつながない。VM で作業するときは、本体が要るファイルを VM のホームにコピーし、書き戻しは道具で行う
- 写真の整理（D-374）：撮影日・場所での並べ替え・重複の検出・縮小版は本体のプログラムで行う（LLM なし・0 円）。中身での分類は画像を読める役割（既定はクラウド）で、件数と費用を先に見積もって見せる。顔で人を見分けるのはやらない
- チャットに画像を添付できる（D-376）。元の画像は保管庫に置き、汚染の印を付ける

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 保管庫を VM にそのままつなぐ | VM のコマンドで自由に整理できる | 消す・上書きを判定できない（ADR-061） | 家の写真は取り返しがつかない |
| 写真の分類も全部ローカル | 家の外に出ない | ラズパイでは画像を読む力が足りない | 既定はクラウド、PC があれば切り替え（ユーザー） |

## 影響
- 保管庫の索引 `vault_files`・添付 `chat_attachments` を足す
- 写真を送るたびに台帳（ADR-074）に残る。見積もりを出してから送る（R-108）
- 保管庫そのものの控えは任意（毎週、別のディスクか NAS へ。NFR-095）
