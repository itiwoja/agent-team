# ADR-051：書き込みの出口（gateway）は本体の中の部品にする
- 状態：承認（2026-10-24 にユーザーが承認：D-172） ／ 日付：2026-10-23 ／ 決定者：Claude判断（提案）→ ユーザー
- 影響する ID：FR-081, NFR-072

## 状況
Cloudflare 版・古い Node 版では、gateway を別の Worker・別のプロセスにして、資格情報を持つ場所を分けていた。Linux 版では持ち主1人・1台のホスト。

## 決定
gateway は本体の中のモジュールにする。資格情報（カレンダーの refresh token・GitHub App の鍵）を使えるのは gateway のモジュールだけにし、依存の検査（dependency-cruiser）で runner・edge から直接届かないことを確かめる。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| gateway を別のコンテナにする | プロセスで秘密を分けられる | コンテナとトークンが増える | 1人で使うには益が小さい |

## 影響
- 本体が乗っ取られると資格情報も使われる。カレンダーは専用のカレンダー、GitHub は `main` の保護という今の範囲の絞りで抑える
