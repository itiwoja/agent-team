# ADR-087：未知部分だけ推論し、障害・拒否とは区別する
- 状態：承認 ／ 日付：2026-10-26 ／ 決定者：Claude判断（おまかせ）
- 影響：REQ-121、FR-120・121、TBL-067・068、API-161

## 状況
全体をAIへ戻すと節約と再現性が失われ、完了済みの副作用を繰り返すおそれがある。

## 決定
契約付きholeを永続化し、必要な情報だけで一時的に推論する。回答は本体が検査する。
権限拒否・通信障害・送信結果不明は穴にせず、それぞれ停止・再試行規約・照合へ送る。

## 代替案
| 案 | 良い点 | 悪い点・不採用理由 |
|---|---|---|
| 仕事全体を再実行 | 単純 | 重複操作と推論増加 |
| 毎回専任エージェントを作成 | 履歴を集めやすい | 局所的な判断に永続役割は不要 |

## 影響
checkpoint・effect key・不確定結果の照合が必要。未知の好みは人へ質問する。
エージェント間の再委譲や自律的な組織全体の再編成は追加しない。
