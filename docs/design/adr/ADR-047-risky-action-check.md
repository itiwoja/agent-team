# ADR-047：ブラウザは自由に操作させ、こわい操作だけを申告と合図で確認に回す
- 状態：一部置き換え済み（秘密入力の確認経路 → [ADR-071](ADR-071-human-only-secrets.md)）。他は承認 ／ 日付：2026-10-23 ／ 決定者：ユーザー
- 影響する ID：REQ-082, FR-076, FR-077, TBL-035, TBL-039

## 状況
今の Agent-Team-Open は「書き込みは必ず確認」。ブラウザの操作を全部確認すると使えない。一方で支払いや送信を勝手にされては困る。

## 決定
操作は確認しない。ただし、エージェントの申告（`confirm_action`）か、決まった合図（秘密の欄・確認するドメイン・決まった言葉・キーでの作動・修飾キー・操作の先が分からない・`type` の改行（Enter と同じ判定。D-157）・確認するドメインへの `open_url`（D-158））に当たったら、Kernel の決定論の関数 `judgeBrowserAction` が確認に回す。承認はその1操作だけに効く。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 申告だけ | 作る量が少ない | 申告を忘れたら通る | 漏れが怖い |
| 合図だけ | LLM に頼らない | 見逃しと空振りが出る | 申告で拾える分を捨てる |
| 全部確認しない | 一番速い | 取り返しのつかない操作が通る | ユーザーが選ばなかった |

## 影響
- 確認は別の表 `browser_checks` に置き（ADR-052）、確認の一覧に並べる。操作の先が分からないときも確認に回すのはユーザーの決定（2026-10-24）。確認が多すぎるサイトは「確かめないドメイン」で外せる
- 判定は完全ではない（R-76）。操作の記録で後から確かめられるようにする
- `div` の擬似ボタンも T-3 の対象にする（Q-121 → D-173。box-agent の `clickable`）。
- v1.2（VM 側のレビュー）：T-4 は Ctrl・Alt・Meta つきの Enter も含む（Shift+Enter だけ当たらない）。Enter を含む T-5 と canvas の T-6 は人に回す（D-297）。T-7 は標準のフォームの送信だけで、JS が `form.submit()`・`fetch` で送るものは DOM で分からず拾えない（R-76 の残る危険。D-298）。判定の材料（`form.method`・`editable`・`unresolvedKind`）を inspect に足した
