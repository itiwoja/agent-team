# ADR-077：オートレビューは既定で切る
- 状態：承認（v1.6） ／ 日付：2026-10-26 ／ 決定者：ユーザー
- 影響する ID：REQ-082・103, FR-076・077・099, TBL-051, SCR-010・023, D-351・370。[ADR-064](ADR-064-auto-review.md) を一部置き換える

## 状況
ADR-064 で、合図に当たった操作のうち「外に出ないと言い切れるもの」は LLM のオートレビューに回し、`pass` なら実行するようにした。留守の間に止まらないためである。ただ、これは判定の道に LLM が入ることを意味する。差別化の軸 B（判定が決定論で確かめられる）を言い切るには、既定で LLM を判定に入れないほうがよい。

## 決定
- `review.auto.enabled` を足す。既定は `false`。既定では、ADR-064 でオートレビューに回していたものはすべて人に回る
- `true` にしたときの動きは ADR-064 のまま。オートレビューは通すだけで、止めたら人に回す。外に出す・支払う・消す・秘密は必ず人
- 入れているかを状態欄（SCR-023）と記録（SCR-010）に出す。判定ごとに「誰が決めたか」（`kernel`・`human`・`llm_review`）を残す（ADR-076）

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| オートレビューを外す | 作りが単純になる | 留守の間に止まる回数が増え、入れたい人が選べない | 選べるほうがよい |
| 今のまま既定で入れる | 留守の間に止まりにくい | 既定で LLM が判定に入り、B と言えない | B を優先した |

## 影響
- 成功指標「留守の間に終わる」（01 §2）は、オートレビューを切った既定の状態では人の確認が増える。指標は「入れたとき」で測り、既定での回数も記録する
- `auto_reviews`（TBL-051）は、既定では行ができない
