# ADR-071：秘密入力は交代専用、画像は完全な事前マスク
- 状態：承認（2026-10-25、ユーザー明示決定）
- 対象：IMP-002・003、FR-075〜078・098、TBL-038、API-103・105
## 状況
署名つき履歴の原本保存と秘密非保存が衝突し、操作対象の枠だけでは画像の秘密を隠せない。
## 決定
秘密入力は人への交代専用。AI再送用秘密原本は暗号化しても保存しない。
秘密を含む応答は全体を破棄して会話を閉じ、理由コードだけ残す。通常の安全な履歴は原本のまま再開する。
全可視秘密領域を撮影前に特定・マスク。保証できなければ撮影・保存・外部送信を止め人へ対応要求する。
## 代替案
暗号化原本＋マスク済み投影は初期版では不採用。部分マスクした署名つき履歴の再送もしない。
## 影響
T-1は通常承認でなく交代。VNCは持ち主専用・非記録。安全性を保証できないページではAIが停止する。
ADR-047・064の秘密欄の通常確認経路をこの決定で置き換える。詳細はFR-075。
