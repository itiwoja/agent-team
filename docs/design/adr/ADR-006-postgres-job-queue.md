# ADR-006：ジョブキューを PostgreSQL（graphile-worker）で持つ
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：NFR-017, FR-002, FR-007

## 状況
タスクの状態の変更と、それに続くジョブ（サンドボックスの起動・通知など）の登録がずれると、「タスクは queued なのにジョブがない」といった不整合が起きる。

## 決定
ジョブキューを PostgreSQL 上の graphile-worker で持ち、状態の変更とジョブの登録を同じトランザクションで行う。

## 理由
- 不整合を構造的に防ぐ。
- ベータの規模（NFR-017）では DB の負荷は問題にならない。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| Cloud Tasks / Pub/Sub | — | DB との二重書き込みになる | アウトボックスパターンが別途必要になる |

## 影響
- スループットが数百件/秒を超えるようになったら見直す。
