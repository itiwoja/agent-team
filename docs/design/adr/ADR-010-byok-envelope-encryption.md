# ADR-010：BYOK のキーはエンベロープ暗号化し、復号できるのは `sandbox-edge` だけにする
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：NFR-022, NFR-023, BR-03

## 状況
利用者の LLM の API キー（BYOK）を預かるため、DB が漏れても読めない形で保存し、使える経路を限定する必要がある。

## 決定
キーごとに DEK を作り、AES-256-GCM で暗号化する。DEK は Cloud KMS の KEK（`kek-credentials`）で暗号化する。復号権限は `sa-sandbox-edge` だけが持つ。

## 理由
DB が漏れてもキーは読めず、キーを使える経路を LLM Proxy の1つに限定できる（NFR-022）。
