# ADR-072：副作用後のLLM失敗は停止通知
- 状態：承認（2026-10-25、ユーザー明示決定）
- 対象：IMP-009、FR-091、TBL-038・041〜043・055
## 状況
元依頼を新ターンへ戻すとtool_call_idが変わり、副作用を重複作成できる。
## 決定
3回連続失敗時、確定済み/不明な副作用があれば元wakeはconsumedのまま停止し、自動再受付/再開しない。
確定済み・未完了・結果不明を区別したsystem通知をDB状態と一括確定する。
## 代替案
同一ターンの自動再開は将来検討。初期版では停止を選ぶ。副作用未発生を証明できる場合の従来の限定再受付は維持。
## 影響
確定済み対象を巻き戻さない。持ち主が状態を確認してから追加依頼する。独立した完了通知は受け取る。
