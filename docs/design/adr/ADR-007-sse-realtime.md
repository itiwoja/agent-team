# ADR-007：リアルタイム配信は SSE にする
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：NFR-011, REQ-013

## 状況
タスクの進捗を画面にリアルタイムで表示する必要がある（NFR-011：p95 < 3秒）。

## 決定
`GET /api/v1/tasks/{taskId}/stream` を SSE で提供する。Cloud Run のリクエストタイムアウト（60分）の前にサーバーから切断し、クライアントに `Last-Event-ID` で再接続させる。配信元は PostgreSQL の LISTEN/NOTIFY。

## 理由
- 通信はサーバーからクライアントへの一方向で十分。
- プロキシやモバイルのネットワークとの相性がよく、HTTP のまま扱えて実装が単純。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| WebSocket | — | — | 通信は一方向で足りるため（上記の理由） |
