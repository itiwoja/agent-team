# ADR-027：エージェントによる設定の変更は、Kernel の `classify()` で「広げる変更」だけを人に戻す
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：ユーザー（14 の決定事項）
- 影響する ID：REQ-054, BR-47, BR-51, BR-55, US-044

## 状況
自己設定・自己調整を許すと、エージェント（や、エージェントが読んだ外部の文章）が自分の権限を広げる経路になりうる。

## 決定
- 設定の変更を決定論的な純粋関数 `classify()` で `narrow` / `neutral` / `widen` に分類し、`widen` はユーザーの承認でしか反映しない（BR-47）。
- 外部の内容に影響されたタスクからの変更案は、分類に関係なく確認カードにする（BR-51）。

## 理由
[ADR-017](ADR-017-in-app-definition-default.md)（権限を広げる変更だけ承認を求める）・[ADR-018](ADR-018-model-only-tightens.md)（モデルの判断は厳しくする方向にだけ使う）を、自己設定にも同じ形で適用できる。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 作成者が設計アシスタントと一緒に下書きを編集する（これまで） | 人が事前に確かめられる | 手順が多い | [ADR-026](ADR-026-name-and-ask.md) |

## 影響
- 指示文の変更は `neutral` のため、振る舞いは承認なしで変わりうる。その影響は、境界（BR-20）・汚染の追跡（BR-38〜42）・Intent の承認で抑える。
- `classify()` は `packages/kernel` に置く（[ADR-001](ADR-001-pure-decision-engine.md) と同じ純粋関数）。
