# ADR-012：実効ポリシーは「厳しい方を取る」合成とし、Kernel の純粋関数にする
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：FR-023, BR-20, BR-21, NFR-036, NFR-056

## 状況
エージェントごとに定義（権限・予算）を持たせると、リポジトリのポリシー・Hard Ceiling と組み合わせた「実際に効く権限」を決める必要がある。

## 決定
`compose()` を `decide()` と同じく純粋関数にし、`decide()` には常に合成結果を渡す。`decide()` の拡張は、合成で新しく生まれる項目（`paths.allow`、エージェントの日次費用 `agent_day_usd`）の判定だけに限る。

## 理由
- エージェントがいくつ増えても、判定の実装は1つのまま。
- 合成の結果はスナップショットに残るので、判定を再現できる（NFR-036）。

## 影響
