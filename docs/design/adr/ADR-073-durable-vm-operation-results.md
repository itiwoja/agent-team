# ADR-073：VM破壊的操作の結果はACKまで保持
- 状態：承認（2026-10-25、承認済み改善案の具体化）
- 対象：IMP-005・006、FR-079・084・100、TBL-031、API-108・138・144
## 状況
完了時に印を消すと未受付と成功が区別できず、消去は復元と競合する。
## 決定
復元・作り直し・消去を操作IDで照合し、結果をDB確定後のACKまで永続保持する。
本体とmanager両方で排他する。ACK待ちは再起動後も新しい操作を開始しない。
## 代替案
時間だけで結果を消す方式・noneを成功扱いする方式は不採用。新しいジョブ基盤は導入しない。
## 影響
workspaceに操作ID・不変引数・ACK待ちを追加。通信不明時は排他維持、失敗はbrokenで人に通知。
