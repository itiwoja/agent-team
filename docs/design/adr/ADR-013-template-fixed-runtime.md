# ADR-013：ランタイムはテンプレートに固定し、ユーザーはコードを書かない
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：FR-029, REQ-018

## 状況
ユーザーが作れるエージェントの幅を広げたいが、サンドボックスの中を信頼しない前提（[ADR-003](ADR-003-cooperative-enforcement-in-sandbox.md)）は崩せない。

## 決定
ユーザーが選べるのは、テンプレート・指示・Skill・境界だけ。ハーネスのコードや、コンテナのイメージは差し替えられない。

## 理由
- サンドボックスの中を信頼しない前提を保ったまま、作れるものの幅を広げられる。
- テンプレートの品質はプラットフォームが責任を持って改善できる。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| ハーネスのコード・イメージの差し替えを許す | — | — | 上記の理由（Won't。01） |

## 影響
- テンプレートにない動き（例：複数リポジトリの横断）は作れない。要望に応じてテンプレートを増やす。
- v0.4 で `researcher` / `briefer` / `watcher` / `assistant` を追加。v0.5 からテンプレートはエージェント（設定プランナー）がお願いから選ぶ（[ADR-026](ADR-026-name-and-ask.md)）。
