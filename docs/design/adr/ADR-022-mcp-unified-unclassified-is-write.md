# ADR-022：外部サービスへの連携は MCP に統一し、ツールは「未分類＝書き込み」として扱う
- 状態：承認（[ADR-016](ADR-016-integrations-as-gateway-adapters.md) の連携先の部分を置き換え） ／ 日付：2026-10-01 ／ 決定者：ユーザー（13 の決定事項）
- 影響する ID：REQ-042, REQ-030, REQ-049, BR-42, BR-44

## 状況
サービスごとにアダプターを作る（ADR-016）と、対応できるサービスの数で dots に勝てない。

## 決定
- GitHub 以外の連携は MCP コネクタに統一する。認証情報は Gateway だけが持つ。
- MCP サーバーの注釈（`readOnlyHint` など）は信用せず、ユーザーが `read` と確定したツールだけを読み取りとして扱う。未分類は書き込み扱い。
- ツールの説明と入力スキーマはハッシュで固定し、変わったら `needs_review`（BR-42）。

## 理由
対応サービスを MCP の生態系に任せられる。サーバーの自己申告を信用しないことで、統制の原則の内側に置ける。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 連携先ごとの Gateway のアダプター（ADR-016） | 作用を厳密に検証できる | 対応数で勝てない | 上記の状況 |

## 影響
- 作用の検証（Verify）は GitHub ほど厳密にできない（ツールごとの設定 → [ADR-031](ADR-031-mcp-write-no-auto-retry.md)）。
- ADR-016 のアダプター方式は GitHub（と将来の特別扱いが要るもの）に限る。
- 呼び出しの経路は [07 §MCP の呼び出しの経路](../07_architecture.md#mcp-の呼び出しの経路)。
