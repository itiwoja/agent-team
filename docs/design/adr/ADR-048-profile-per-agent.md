# ADR-048：ブラウザのプロフィールはエージェントごとに残し、VM はタスクごとに起こす
- 状態：承認 ／ 日付：2026-10-23 ／ 決定者：ユーザー
- 影響する ID：REQ-084, FR-074, FR-079, TBL-036

## 状況
ログインが要るサイトで、毎回人がログインするのは手間。VM を起こしたままにするとメモリを食う。

## 決定
Chromium のユーザーデータを、エージェントごとの Docker のボリュームに置く。VM はタスクごとに起こし、終わったら止める。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 毎回使い捨て | 漏れても残らない | 毎回ログイン | 手間 |
| VM をずっと動かす | すぐ使える | ラズパイのメモリが足りない | 資源 |

## 影響
- ログイン済みのプロフィールは、ページの仕掛けで悪用される危うさがある（R-76）。エージェントを分けて、プロフィールの範囲を小さくできる
- プロフィールは書き出しに入れない（FR-082）
