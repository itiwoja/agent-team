# ADR-003：サンドボックス内の判定は「協調的な強制」とし、最終的な防御は境界と差分の検証で行う
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：NFR-018, NFR-019, FR-008, FR-010

## 状況
`run_tests` ではリポジトリのコードを実行するので、サンドボックスの中のランタイムが乗っ取られる可能性がある。

## 決定
ツール呼び出しの判定は LLM Proxy で行い、ランタイムはそれに従う（協調的な強制）。ランタイムが従わない場合に備えて、次の4つを非協調的な強制とする。
1. 認証情報がないこと
2. 通信先の制限
3. サーバー側での差分の検証（禁止パス・ファイル数・適用できるか）
4. LLM 呼び出しは必ず Proxy を通ること（予算）

## 理由
サンドボックスの中を信頼しない前提を守りつつ、禁止された操作をエージェントに早く伝えて、無駄なステップを減らす。

## 影響
- サンドボックスの中での禁止パスの「読み取り」は技術的には防げない。秘密情報はリポジトリに置かないことを前提にし、ドキュメントでそう案内する。
- テンプレート固定（[ADR-013](ADR-013-template-fixed-runtime.md)）はこの前提の上にある。
