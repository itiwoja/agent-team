# ADR-086：検証ゲートを満たす版を自動採用する
- 状態：承認 ／ 日付：2026-10-26 ／ 決定者：ユーザー（自動採用）・Claude判断（おまかせ：詳細）
- 影響：REQ-120・122、FR-119・122、TBL-065・066、API-160

## 状況
ユーザーは学習結果の都度承認ではなく、条件達成での自動採用を選択した。

## 決定
静的検査・再生・反例・シャドー・依存版確認を通した版だけactiveにする。採用処理は候補LLMから独立させる。
版は不変。依存条件変更・出力契約違反・証拠の期限切れで失効する。

## 代替案
| 案 | 良い点 | 悪い点・不採用理由 |
|---|---|---|
| 人が版を承認 | 意図を確認できる | ユーザーが自動採用を選択 |
| 成功1件で採用 | 学習が速い | 丸暗記と適用範囲の誤りを検出しにくい |

## 影響
有限試験は汎化の証明ではない。ガードと出力契約を実行時にも検査する。
外部への書込承認は既存Kernelの契約を継承し、プログラム採用で権限を増やさない。
