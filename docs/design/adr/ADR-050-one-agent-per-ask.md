# ADR-050：1件の依頼はエージェント1人に任せる（編成と育つ仕組みを外す）
- 状態：置き換え済み（→ ADR-059。2026-10-24） ／ 日付：2026-10-23 ／ 決定者：ユーザー
- 影響する ID：REQ-079, FR-061, FR-064（使わない）, FR-085

## 状況
最初の版に入れるものを選んだとき、ユーザーは「複数エージェントの編成」と「スキルが育つ仕組み」を選ばなかった。要らない機能を増やしすぎない方針。

## 決定
設定プランナーは「使い回す1人」か「新しく作る1人」だけを返す。並列・まとめ・順番の形と連絡板（旧 FR-064）、スキルの案と整理は作らない。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 編成を残す | 大きな依頼を手分けできる | VM の同時数がすぐ足りなくなる。作る量が多い | ユーザーが選ばなかった |

## 影響
- 編成用の表・列（`ask_members`・shape の値など）は1人の値で使い、表を落とすかは移すときに決める
- パックと手で書いたスキルは残す（Q-114・Q-115 → D-176・D-177）。パックは用途の単位で、振り分けに使う（[ADR-053](ADR-053-pack-by-purpose.md)）。1 件 1 人は変わらない
