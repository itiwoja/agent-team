# ADR-085：学習結果は制限IRと契約付きの穴で表現する
- 状態：承認 ／ 日付：2026-10-26 ／ 決定者：Claude判断（おまかせ）
- 影響：REQ-119・121、FR-117・118・120・121、TBL-064・065

## 状況
自然言語スキルは毎回推論を必要とし、任意コードは検証範囲が大きい。

## 決定
型付きの既知演算・read・guard・hole・proposeだけで構成する不変DAGを使う。未知部分は穴として残す。

## 代替案
| 案 | 良い点 | 悪い点・不採用理由 |
|---|---|---|
| 自然言語スキル | 柔軟 | 推論削減を保証する構造にならない |
| 任意Python/JS生成 | 表現力 | 正しさ・副作用・資源消費の検証範囲が広い |

## 影響
最初は日程調整の型付きAPI操作のみ。任意画面操作の自動コンパイルや仕事横断の自動合成は対象外。
既存スキルを育てない決定D-177は自然言語スキルに限り継承。実行IRは別の学習対象として追加する。
