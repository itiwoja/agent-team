# ADR-005：承認を intentHash に結びつけ、実行後に tree SHA で検証する
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：REQ-006, FR-011, FR-012, BR-15

## 状況
承認した内容と、実際に実行される内容が一致することを保証する必要がある（REQ-006）。

## 決定
承認するときに、画面に表示した intentHash を送らせ、実行のときにも再計算して照合する。PR を作成した後に、head のコミットの tree SHA を期待値と比べる。

## 理由
- 承認後のすり替え（TOCTOU）を防ぐ。
- 「承認したものが作られた」ことを事後に証明する（REQ-006）。

## 代替案
—（元の記述なし）

## 影響
- MCP の書き込みでは、intentHash にコネクタ・ツール・引数・ツールのハッシュ（説明文・入力スキーマ・`arg_roles`）・実効ポリシーのハッシュを含め、Gateway は固定した引数をそのまま `tools/call` に渡す（v0.6）。
- MCP には読み戻しの標準がないため、tree SHA に相当する検証はツールごとの設定（`none` / `readback`）になる（[ADR-031](ADR-031-mcp-write-no-auto-retry.md)）。
