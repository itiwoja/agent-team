# ADR-079：家に置く常駐エージェントにし、非エンジニアにはセットアップ済みのラズパイで届ける
- 状態：承認（v1.7） ／ 日付：2026-10-26 ／ 決定者：ユーザー（対象・届け方・API キー）・Claude判断（初回の手順）
- 影響する ID：REQ-112・118, US-078, UC-067, FR-109, NFR-062・081・092・094, API-157, SCR-033, R-111・112, D-371・372・382〜384。[../../oss-and-business.md](../../oss-and-business.md) の決定 3 を見直す

## 状況
v1.6 で A・B・C（閉域・判定の検証・モデル選択）を足したが、どれも「統制」の話で、使っていて便利とは言えなかった。Fable 5.1 の助言では、Muse・Dots が作りの上で届かないのは**家の中**（家の LAN・家のファイル・家電）だけだった。ユーザーは「セットアップしたラズパイを家に置き、スマホから頼むだけで、非エンジニアでも IoT・写真の管理・家計簿ができる」形を選んだ。これまでは「非エンジニアの一般向けには展開しない」（2026-10-24）としていた。

## 決定
- 対象を家の人（非エンジニアを含む）に広げる。持ち主 1 人は変えない（家族は次の版の候補：REQ-118）（D-371）
- 届け方はセットアップ済みのラズパイ（キット）。推奨はラズパイ 5 の 16GB、最低 8GB。USB の SSD つき。入口は Tailscale（外出先からも使え、正しい証明書でパスキーが使える）（D-372）
- 初回は 5 段：電源と LAN → スマホに Tailscale を入れて QR で招待を受ける → QR からパスキーを登録 → API キーを貼る → 最初のお願い。目標は 15 分・非エンジニア 3 人中 2 人（NFR-094）
- API キーは最初は持ち主が自分で取る。写真つきの手順書とスマホで貼れる画面を用意する（D-384）
- 「一般向けには展開しない」を見直す。キットで少数から手渡し・販売する。ストア配布・ホスティング版・API の肩代わりはやらない（D-382）
- ADR-075（チームで 1 台）は不採用にする（D-383）

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 開発者向けのまま | 支える範囲が小さい | 家の中の便利さが開発者にしか届かない | ユーザーが家の人を選んだ |
| 書き込むだけのイメージを配る | キットを作らなくてよい | SD カードへの書き込みが非エンジニアには難しい | 最初の一歩で止まる |
| こちらで API を用意して月額 | 非エンジニアに優しい | サービス提供者になり、費用とサポートの責任を負う | キットを売る段階で考える |

## 影響
- 画面は非エンジニアがスマホで使う前提にする（06）。はじめての設定の画面（SCR-033）を足す
- サポートが重くなる（R-111）。少数から手渡しで始め、状態の画面と手順書で減らす
- キットの作り方（イメージ・QR・手渡し）を運用契約に書く（11）
