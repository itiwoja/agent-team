# ADR-043：VM はコンテナに仮想画面と Chromium と VNC を入れたものにする
- 状態：承認 ／ 日付：2026-10-23 ／ 決定者：ユーザー（中身の部品は Claude判断（提案））
- 影響する ID：REQ-081, REQ-083, FR-074, FR-078, NFR-066

## 状況
API・MCP のないページをコンピューターユースで操作させたい（ユーザーは「VM」と呼んだ）。人も画面を見て、交代して操作したい。ラズパイと WSL2 で動く必要がある。

## 決定
Docker のコンテナに Xvfb・軽いウィンドウマネージャ・Chromium・x11vnc＋websockify・box-agent を入れる。VM の入口（API-101〜106）を決めておき、中身を microVM に差し替えられるようにする。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| microVM（Firecracker など） | カーネルまで分かれる | KVM が要る。WSL2 は入れ子の仮想化、ラズパイは設定が要る | 置き先を選ぶ |
| ふつうの VM（QEMU/KVM） | 一番強い隔離 | 重い。ラズパイのメモリでは厳しい | 同上 |
| 画面なしのブラウザ＋CDP の screencast | 軽い | ダイアログやブラウザの外が見えない。人の交代が難しい | 交代が要る |

## 影響
- 隔離はコンテナの強さまで。権限を外し、ネットワークを分けて補う（NFR-066、ADR-045）
