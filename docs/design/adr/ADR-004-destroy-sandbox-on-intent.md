# ADR-004：Intent を出した時点でサンドボックスを破棄し、差分をサーバーに保存する
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：FR-010, FR-012, NFR-048, NFR-049

## 状況
承認は数時間後になることもある。

## 決定
Intent を受け付けた時点でサンドボックスを停止する。差分・PR 案・期待する tree SHA は DB に保存し、実行はサーバー側（`gateway`）で差分をベースに適用して行う。

## 理由
- 待っている間のサンドボックスの費用をなくす。
- 実行する内容を、承認した内容に固定する。

## 代替案
—（元の記述なし）

## 影響
- 却下後に作り直す機能（Won't）を将来入れる場合は、新しいサンドボックスで作業をやり直す必要がある。
- MCP の書き込み（v0.6）では、1タスクで複数の Intent を出せる。エージェントは結果を待たずに続け、ループが終わった時点で承認待ちがあれば `awaiting_approval` にし、サンドボックス（または実行用のプロセス）を終了する（[ADR-031](ADR-031-mcp-write-no-auto-retry.md)）。
- 永続ディスクを付ける拡張は [ADR-020](ADR-020-ephemeral-compute-persistent-disk.md)（フェーズ2）。
