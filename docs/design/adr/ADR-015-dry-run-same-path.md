# ADR-015：試し実行は本番と同じ経路を通し、外部作用だけを Gateway の手前で止める
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：FR-026, BR-24, NFR-059, REQ-022

## 状況
公開前にエージェントの動きを確かめる「試し実行」を、どの経路で動かすかを決める必要がある。

## 決定
試し用の別ランタイムは作らず、`is_dry_run` のフラグで Intent を `simulated` にする。

## 理由
- 試し実行で確かめたことが、本番の動きとずれない。
- 判定・予算・Breaker も本番と同じに働くので、「試し実行では止まらなかったのに本番で止まった」が起きにくい。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| 試し用の別ランタイム | — | 本番の動きとずれる | 上記の理由 |

## 影響
- 試し実行でも LLM の費用がかかる。上限を $1 にする（BR-24）。
- v0.5 で試し実行は「詳細設定」に移った（[ADR-026](ADR-026-name-and-ask.md)）。
