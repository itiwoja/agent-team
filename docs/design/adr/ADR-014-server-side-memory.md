# ADR-014：メモリはサーバー側に置き、完了したタスクの書き込みだけを有効にする
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：—（元の記述なし）
- 影響する ID：FR-031, BR-26, NFR-057, REQ-025

## 状況
メモリは、プロンプトインジェクションの内容を次のタスクに持ち越す経路になりうる。

## 決定
メモリは DB に置き、`remember` は Kernel で判定する。書き込みは、そのタスクが完了したときだけ有効にする。項目ごとに書き込んだタスクを記録し、1件ずつ削除できるようにする。

## 理由
- 停止・却下されたタスク（異常な動きをした可能性が高い）の影響を次に残さない。
- dots への「メモリを項目単位で消せない」という批判にも応える。

## 影響
- 完了したタスクの中で混入した内容は残りうる。項目の出どころ（タスク）をたどれるようにして、人が見て消せるようにする。
- v0.6：メモリの有効化は `succeeded` と `completed`（`report` / `actions_declined`）で行う（15 のタスクの終わり方）。
