# ADR-023：Web の読み取りは組み込みにし、専用のプロキシを通す
- 状態：承認 ／ 日付：2026-10-01 ／ 決定者：ユーザー（13 の決定事項）
- 影響する ID：REQ-044, NFR-019, BR-38

## 状況
リサーチ系の用途は Web の読み取りが中心。一方で、サンドボックスに任意の通信を許すと（`shell_network`）、情報の持ち出しの経路になる。

## 決定
`web_search` / `web_fetch` を `sandbox-edge` のツールとして提供し、GET / HEAD のみ・認証情報なし・私的アドレス拒否の Web 取得プロキシを通す。`shell_network` は deny のまま。

## 理由
読み取りの用途を満たしつつ、サンドボックスから直接インターネットに出る経路を作らない。

## 代替案
| 案 | 良い点 | 悪い点 | 不採用の理由 |
|---|---|---|---|
| サンドボックスに任意の通信を許す（`shell_network`） | — | 情報の持ち出しの経路になる | 上記の状況 |

## 影響
- URL のクエリ文字列に情報を載せて持ち出す経路は残る。BR-38〜39（汚染後の書き込みの制限）と、`web.max_fetches_per_task`・ドメインの制限で緩和する（完全には防げない。未決）。
- プロキシの規則は [07 §Web 取得プロキシ](../07_architecture.md#web-取得プロキシ)。
