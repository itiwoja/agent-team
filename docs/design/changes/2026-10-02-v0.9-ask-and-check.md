# 変更：毎日使う画面を「頼む・チェック」の1枚にする（v0.8 → v0.9、2026-10-02）
> **3行で**：毎日使う画面を SCR-019「頼む・チェック」の1枚にし、承認も同じ ○（5秒の取り消し猶予つき）、聞き返しは選択肢のボタンで答えるようにした ／ 5タブの管制盤では用事のたびに「どの画面に行くか」「誰に頼むか」を考える必要があり、「頼むだけ・チェックするだけ」にしたいというプロダクトオーナーの要望に合わなかったため（[ADR-034](../adr/ADR-034-one-screen-ask-and-check.md)、[D-42〜45](../decisions.md#d-42)） ／ いちばん大きい影響は、承認の確認シートをやめて取り消しの猶予にしたことと、SCR-002・003・006 が日常の入口から外れたこと。

## 🧭 判断してほしいこと
- 取り消しの猶予の長さ（A-91、仮に5秒）と「見てほしいもの」の並び順（A-92）は、プロトタイプを実機で触って決め直す。
- 「チェック済み」を記録する置き場と、依頼を受ける API は未設計（T-1 の設計作業で決める）。
