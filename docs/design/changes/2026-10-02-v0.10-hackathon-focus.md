# 変更：ハッカソン版の範囲を「仕入れ係のリハーサル一周」に絞る（v0.9 → v0.10、2026-10-02）
> **3行で**：ハッカソン版の Must を、仕入れ係のリハーサル一周（試す → すり抜け → 締める → 再試験）＋監査ログ＋Kill Switch に絞った。Cloud Run は3サービスにし、初日にデプロイする。リハーサルを作る前に「Gemini が罠に引っかかるか」を計測する ／ 10/2 の時点で実装がなく、旧版の範囲（5サービス・3つの題材・終盤のデプロイ）では、ファイナリストの選考で効く「URL で動く」「3分で伝わる」を落とすおそれが大きかったため（[D-51〜56](../decisions.md#d-51)） ／ いちばん大きい影響は、runner・sandbox-edge を別のサービスにしないこと（境界は CI の import の検査で守る）と、脇役の2つの題材が Should になったこと。
