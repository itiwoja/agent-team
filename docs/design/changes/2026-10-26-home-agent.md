# 家に置く常駐エージェント（v1.6 → v1.7）
- 日付：2026-10-26
- 対象：設計書（docs/design/）と `docs/oss-and-business.md`。コード・実装手順書（docs/implementation/）は変えていない

> **3行で**
> 1. v1.6 の A・B・C は「統制」の話で、使っていて便利とは言えなかった。Fable 5.1 の助言から、Muse・Dots が作りの上で届かない**家の中**（家の LAN・家のファイル・家電）を便利さの軸にした。
> 2. 非エンジニアにはセットアップ済みのラズパイ（キット）で届け、家の保管庫（写真・書類）・レシートからの家計簿・Home Assistant 経由の家電・チャットの画像の添付・家の中の判断モデルを足した。
> 3. 鍵・暖房・ガスなどの家電と、保管庫のファイルを消す操作は、Kernel の規則で必ず人に聞く。チームで 1 台は不採用。「一般向けには展開しない」はキットで届ける形に見直した。

## 追加：Sign in with ChatGPT（同じ日。D-385〜390・ADR-084）
非エンジニアの一番の壁だった API キーを取る手間を、ChatGPT のアカウントでのサインインに置き換えた。

| 決定 | 中身 |
|---|---|
| D-385 | 接続先 `openai_chatgpt`。OSS の自分での登録（秘密の鍵・API キーなし）。Responses API だけ |
| D-386 | デバイスコードでサインイン（キットのコードをスマホで承認）。トークンは本体に暗号化 |
| D-387 | キットの初回設定では「ChatGPT でサインイン」を先に。API キーは別の道 |
| D-388 | 上限に達したら、ほかの支払いに切り替えず止めて知らせる |
| D-389 | 自動のきっかけでは既定で使わない（無料の枠を守る・利用規約が分かるまで） |
| D-390 | 画像・computer use は確かめてから。非公式の OAuth は使わない |

- 公式のヘルプセンター：「対応しているオープンソースのツールは、すべての ChatGPT の利用者が使える」。無料の人も使える見込みだが、枠は小さい
- 確かめること（R-113）：利用規約（常駐・自動の使い方）、無料の枠の大きさ、画像の入力、computer use の可否。無料のアカウントで実際に試す

| ID | 受入条件 |
|---|---|
| FR-116 | キットで「ChatGPT でサインイン」を押し、スマホでコードを承認すると、API キーなしで最初のお願いが通る。429 を返させると、そのタスクが止まり知らせが来て、ほかの支払いには切り替わらない。ルーチンからは既定で ChatGPT の枠を使わない |
