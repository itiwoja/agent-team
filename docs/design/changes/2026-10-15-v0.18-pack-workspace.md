# 変更：パックの作業場と入れたときの演出（v0.17 → v0.18、2026-10-15）
> **3行で**：パックは棚の札の一覧で、入れても担当の姿が見えず、依頼の入口もなかった。`/packs/:packId` を「パックの作業場」にし、担当が机で働く画面にした（待機中は独り言、頼むとすぐ応答）。入れた直後は全画面の演出（たまごから担当が生まれ、「チームがそろいました」）を出す。依頼は作業場から `POST /asks` の `packId` で出し、設定プランナーはそのパックの担当で分担する。

## 🧭 判断してほしいこと
- 作業場の画面に SCR 番号を付けるか。06 に `/packs` の行がまだ無い（中身は [D-117](../decisions.md#d-117) に記した）。付けるなら次の版で 06 に SCR を足す。
- `POST /asks`（API-072 の仮番号。[entrance.md](../06_ux_design/entrance.md) で「提出後に反映」）と、`GET /packs`・`POST /packs/{packId}/install` の `agents[].agentId` を 09 に載せる時期。今の 09 にはどちらも無い。
