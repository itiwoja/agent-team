# 1. 知識はファイルに置く

ファイル: `スクリーンショット 2026-10-23 211140.png`

```
agent-home/
  memory/
    profile.md            always in the prompt
    log/2026-10.md        dated facts, one per line
  skills/
    linkedin-sourcing/
      SKILL.md            "Use this when…"
    weekly-metrics/
      SKILL.md
  routines/
    morning-brief         prompt + weekdays 8:00
```

- `memory/profile.md` … 常にプロンプトに入れる
- `memory/log/2026-10.md` … 日付つきの事実を 1 行に 1 つ
- `skills/<名前>/SKILL.md` … 「Use this when…」（いつ使うか）を書く
- `routines/morning-brief` … プロンプト ＋ 平日 8:00
