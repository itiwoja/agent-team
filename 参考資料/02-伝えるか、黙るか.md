# 2. 伝えるか、黙るか

ファイル: `スクリーンショット 2026-10-23 211312.png`

入ってくるもの（左側、すべてルーターへ集まる）:

- アプリからのあなた
- ルーチン：予定・webhook
- Slack のメンション・DM
- 電話や会議
- ほかのエージェント
- 裏の作業の完了
- 予約した確認

（途中の線に「メモ」「“」の札が付いている）

流れ:

1. **ルーター** … 重複を捨て、会話を選ぶ
2. **会話のキュー** … 1 ターンずつ
3. **伝える価値は？**（分岐）
   - yes → **ふさわしい場所へ送る**
   - no → **送らない**

補足:

- 起こされた理由を記録：あなた／ルーチン／外のサービス
- 「進みました！」が 3 つ重なっている絵（＝何度も同じ報告を送らない、の例）
