# 6. ツールごとに画面を出し分ける

ファイル: `スクリーンショット 2026-10-23 211624.png`

ヘッダー: `GROK BOT / 080` ・ 章「ハーネス」

中央に `SendToUser`。4 つの出し分け:

| 種類 | 説明 |
|---|---|
| サインイン：1Password | 開いているサイトにだけ自動入力（**パスワードはモデルに渡らない**） |
| 支払いの承認 | 「許可」を押すまで待つ |
| メールの下書き | 見せてから「送信」か「破棄」 |
| リアクション | 返事がいらないときは ♥ だけ |

字幕: 支払いは「許可」を押すまで待ち、メールは下書きを見せて、送るかどうかを選ばせます。
