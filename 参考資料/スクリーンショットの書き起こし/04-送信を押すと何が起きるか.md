# 4. 送信を押すと何が起きるか

ファイル: `スクリーンショット 2026-10-23 211456.png`

| 段階 | 流れ |
|---|---|
| **1 送信** | アプリがすぐに表示 → 固有の ID を付けて保存 → サーバーは見た ID を捨てる |
| **2 ターン** | 会話のキューに入る → 1 ターン：モデル・ツール → 1 歩ごとに DB へ保存 |
| **3 合図** | サーバーが小さな合図 → アプリが合図を受ける → 新しいメッセージを取りに行く |
| **4 順番** | 更新には通し番号 → 41、42、43 の順に反映 → 抜けたら DB から読み直す |

- 「3 合図」の上の注記: **合図に中身はない（落としても困らない）**
