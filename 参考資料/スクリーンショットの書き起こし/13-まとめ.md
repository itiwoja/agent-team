# 13. まとめ

ファイル: `スクリーンショット 2026-10-23 211941.png`

3 つの箱の全体図。

- **アプリと窓口**
  - デスクトップアプリ
  - スマホと Web
  - Slack
  - メール・webhook・予定
  - 電話と会議
- **サーバー：エージェントを動かす**
  - 受付：入力を確かめて振り分ける
  - キュー：会話ごとに 1 本
  - モデル
  - エージェントループとツール
    - サブエージェント ／ ファイル ／ キャッシュ
  - 保存した状態：データベースとストレージ
- **専用のコンピュータ：ツールを動かす**（上に「眠る → 起きる」）
  - ファイルと接続のサーバー
  - コマンド実行：シェル・ファイル
  - デスクトップと Chrome

矢印:

- アプリと窓口 → 受付: **送信**
- エージェントループとツール → 専用のコンピュータ: **ツール**
- 保存した状態 → アプリと窓口: **更新**（点線）
